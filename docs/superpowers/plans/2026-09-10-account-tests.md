# 账号与自选测试实施计划

目标：统一官网入口，登录后通过八位账号做朋友测试、自选25题创建测试、查看自己的排行榜。

已确认：名字、唯一八位纯数字账号、至少8位密码与确认密码；暂不找回密码。75题按分类浏览，自选25题后回答；重建提醒清空旧测试与排行榜。结果默认3个差异，可展开全部。

实施选择：账号保留前导零；昵称1–20字符、密码8–128字符；同人每份测试一次提交；账号身份决定归属，结果仅答题者及测试创建者可见。覆盖在新答卷提交成功时于数据库事务内完成；选题及答题中途退出不清除旧数据。并发重建用旧测试ID比较，重复提交使用幂等键。旧匿名数据保留在库，但旧传播入口停止服务，不凭昵称自动认领。
