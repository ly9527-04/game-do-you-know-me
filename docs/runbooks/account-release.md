## 本轮实现

登录/注册使用名字、唯一八位纯数字账号、8–128字符密码与确认密码；账号保存为文本以保留前导零。第一版不找回密码。密码使用带随机盐的scrypt，登录凭据为30天HttpOnly不透明会话，数据库仅存令牌哈希，退出撤销会话。

首页三个入口：做朋友的测试、创建/重新创建自己的测试、我的排行榜。朋友通过账号查找。75题按7类浏览，任意选25题后作答；不限制分类配额。结果默认3处差异，查看更多展开全部，仅创建者和作答者能访问。

每账号只保留一个当前测试；确认覆盖后进入选题，新答卷成功保存时事务替换旧测试并清空其排行榜、答案，失败回滚。旧匿名数据保留，不凭昵称自动认领；旧分享/管理/OG入口已停止服务。每用户每个当前测试提交一次，重复请求返回原结果；重建后允许再次挑战。

## 环境与反向代理

配置SUPABASE_URL、SUPABASE_SECRET_KEY、RATE_LIMIT_SECRET、NEXT_PUBLIC_SITE_URL。服务端密钥不能放入NEXT_PUBLIC变量。NEXT_PUBLIC_SITE_URL必须与浏览器实际origin一致，包括localhost与127.0.0.1区别。线上会话Cookie带Secure和__Host-前缀，仅HTTPS。

限流依赖可信代理覆盖x-forwarded-for，不能让公网客户端伪造。登录按账号和IP分别限流；创建、提交沿用原有限流。直接本机服务若缺少可信IP头需通过本机测试代理或测试请求设置；不可为了本地测试放松生产校验。

MANAGEMENT_SESSION_SECRET只保留给旧代码兼容，不再用于新账户登录。
